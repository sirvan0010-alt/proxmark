## 3. BWM protocol audit

### Verified

- BWM frame kinds: request/response/broadcast.
- Frame length handling.
- CRC calculation scope is explicitly documented as including magic + command ID + length + payload.
- CRC provenance points to the specified `Proxmark5_BWM_esp32` firmware source and commit.
- Command definitions are preserved as an upstream snapshot rather than invented locally.
- Stream parser has fragmentation, garbage, invalid-length, CRC and resynchronisation tests.

### Important truth boundary

The framing and command-code provenance is **PROTOCOL VERIFIED**, not `HARDWARE VERIFIED`.

Per-command payload layouts remain deliberately below high confidence until the firmware response-building path and/or the real device confirms them.

**BWM protocol status: PASS with explicit hardware-validation boundary**

## 4. Read-only safety audit

The previous implementation had an architectural weakness: `QueryAsync` was public and accepted any `BwmCommandCode`, even though the adapter was documented as read-only.

This audit corrected that.

`BwmReadOnlyAdapter` now has an explicit allow-list containing only the five commands currently implemented by the adapter:

- `GetVersionInfo`
- `GetDeviceModel`
- `GetAppCompileDatetime`
- `GetSysFreeHeap`
- `GetSysBaseMacAddr`

Mutating commands are rejected before the transport is called.

Cancellation is also preserved instead of being swallowed as a generic transport failure.

Tests were added for both properties.

**Read-only enforcement: PASS**

## 5. Simulator audit

The simulator exists as a separate project and is explicitly compiled by CI on Ubuntu and Windows.

The test project references the simulator, and behavioural tests cover deterministic state and explicit unknown/error behaviour.

The simulator is correctly treated as `SIMULATED` evidence rather than hardware evidence.

### Remaining limitation

The simulator is intentionally not a substitute for a real PM5. It must not be promoted to a hardware truth source merely because more simulated behaviours are added.
